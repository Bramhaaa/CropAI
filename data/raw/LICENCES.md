# Dataset sources and licences

Keep the original licence/readme distributed with each download beside the
corresponding raw dataset. This file records the source used by CropAI.

| Dataset | Local location | Source |
| --- | --- | --- |
| PlantVillage colour images | `disease/plantvillage/` | https://github.com/spMohanty/PlantVillage-Dataset |
| Crop Recommendation Dataset | `recommendation/Crop_recommendation.csv` | https://www.kaggle.com/datasets/atharvaingle/crop-recommendation-dataset |
| Crop Production in India | `yield/crop_production.csv` | https://www.kaggle.com/datasets/abhinand05/crop-production-in-india |
| ERA5 climate data | `climate/era5/` | https://cds.climate.copernicus.eu/ |

The data-preparation and training code must cite each source in generated
reports and must not redistribute the raw files.
